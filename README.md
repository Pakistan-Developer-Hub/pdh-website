# Pakistan Developer Hub Website

Official static website for Pakistan Developer Hub (PDH).

## Files
- `index.html` — website content
- `css/styles.css` — responsive styling
- `js/config.js` — central social/contact configuration
- `js/main.js` — mobile navigation and dynamic year
- `assets/pdh-mark.svg` — simple PDH mark

## Deploy to Vercel
1. Upload these files to a GitHub repository.
2. In Vercel choose **Add New → Project** and import the repository.
3. Select **Other** as framework preset.
4. No build command is required for this plain HTML/CSS/JS site.
5. Deploy.

## Before launch
- Confirm you want your phone number publicly displayed.
- The YouTube link currently points to the founder's personal channel, not a separate PDH channel.
- Add confirmed team member profiles and photos only with permission.
- Add official Instagram and future social links when those accounts exist.
- Review all links and the site on mobile and desktop.
